[리밸런싱 정책]
- 종목 교체는 하지 않을 것이며, 필요 시 내가 직접 수동으로만 한다.

[할 일]
1. scripts/select_universe.py (수동 실행용):
   - pykrx로 기준일의 KOSPI/KOSDAQ 전체 종목의 시가총액과 최근 N거래일(기본 20일) 일평균 거래대금 조회
   - 선정 로직(파라미터로 조정 가능, 기본값 명시):
     · 시가총액 순위 + 거래대금 순위를 각각 매겨 합산(또는 각 z-score 합)해 종합 순위 산출
     · 상위 25종목 추출
     · 우선주/스팩/ETF/ETN/리츠/관리·정리매매 종목은 제외(가능한 범위에서 필터)
   - 결과를 콘솔에 표로 출력(코드, 종목명, 시장, 시총, 거래대금)
   - 확정 시 core/universe.py 파일을 자동 생성/덮어쓰기
2. core/universe.py (스크립트가 생성하는 "고정" 파일):
   - KR_UNIVERSE = [(종목코드, 종목명, 시장)] 리스트 (시장은 "KOSPI" 또는 "KOSDAQ")
   - CODE_TO_NAME, NAME_TO_CODE, CODE_TO_MARKET 딕셔너리
   - TARGET_COLUMNS = ML/분석에서 쓸 종목 컬럼명(종목명 기준 통일)
   - SELECTED_AT = 선정 기준일 문자열 (수동 리밸런싱 시점 추적용)
   - 파일 상단 주석에 선정 기준일/기준/종목별 시총·거래대금 메모
3. 종목코드는 반드시 6자리 문자열("005930")로 보존(앞자리 0 유지).
4. validate_universe() 함수: 코드 6자리 여부, 중복 없음, 시장 값 유효성 검사.

[완료 기준]
- `python scripts/select_universe.py` 실행 시 상위 25종목 표가 출력되고 core/universe.py가 생성됨
- `python -c "from app.core.universe import KR_UNIVERSE, validate_universe; validate_universe()"` 통과
- universe.py에 선정 기준일이 기록되어 있어 나중에 수동 리밸런싱 이력을 알 수 있음
